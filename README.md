# Smart Service Provider System

A full-stack web application designed to connect users with skilled service providers efficiently.

## 🛠️ Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MySQL

## 📂 Project Structure
- `/backend` - Node.js REST API server & database logic
- `/frontend` - React user interface and components
